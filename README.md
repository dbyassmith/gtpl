# GTPL

Minimal public website for the Georgia Tech Premier League.

The site has three routes:

- `/` — live countdown to August 27, 2026 at 1:00 p.m. Eastern
- `/constitution` — the complete league constitution
- `/dumps/2026/1` — Week 1 of The Natty Dump

## Development

```sh
pnpm install
pnpm dev
```

## Production build

```sh
pnpm build
```
